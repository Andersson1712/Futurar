# i18n guide

> Last reviewed: 2026-10-01

## Policy

- **UI copy is es-AR** (Argentina). All user-facing strings go through the
  translation layer — never hardcode UI text in components.
- **Code, comments, identifiers and commits are English** (Conventional Commits).
- Backend error codes are English identifiers; the UI maps them to Spanish copy.

## Current implementation

There is no external i18n library yet. The layer is
[`utils/messages.ts`](../utils/messages.ts):

- `TRANSLATIONS` — a flat, typed dictionary of UI strings.
- `MessageKey` — `keyof typeof TRANSLATIONS`, so `t()` only accepts known keys.
- `t(key: MessageKey): string` — returns the string or throws
  `Missing translation for key: <key>`.
- `ERROR_MESSAGES` + `messageForErrorCode(code?)` — maps backend `AiError` codes
  (`VALIDATION_FAILED`, `NOT_FOUND`, `RATE_LIMITED`, …) to Spanish copy, with a
  generic fallback.
- `MESSAGES` — nested generation/error copy used by the generation flow.

```ts
import { t, messageForErrorCode } from '../utils/messages';

speakWithState(t('wizard.menuTitle'));
setError(messageForErrorCode(err.code));
```

## Adding or changing copy

1. Add the key/value to `TRANSLATIONS` in `utils/messages.ts`.
2. Use `t('your.key')` in the component — `MessageKey` autocompletes and fails the
   type check if the key doesn't exist.
3. Run the guard tests: `npm run test -- utils/messages.test.ts`. They assert that
   no translation is empty and that `t()` returns each dictionary value.

Names use dotted namespaces by area: `controls.*`, `scan.*`, `wizard.*`,
`editor.*`, `reader.*`, `library.*`.

## What is guarded today

- `utils/messages.test.ts` (SPEC-018): no empty translations, `t()` resolves every
  key, unknown keys throw, error-code mapping falls back to the generic message.
- Critical student-flow strings are centralized and read through `t()`.

## Known gap / next step

The full extraction is pending: some panels still contain literal Spanish
strings, and there is only one locale. A follow-up should move every remaining
literal into `TRANSLATIONS` (or introduce namespaces/locale files) without
changing user-visible copy. Prefer adding keys as you touch a screen, and keep
the guard tests green.

## Accessibility tie-in

Copy choices affect TTS and readability: keep labels short, avoid ambiguous
abbreviations, and remember the UI is read aloud by the voice assistant. See the
[accessibility guide](accessibility/guide.es.md).
